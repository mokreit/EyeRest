# EyeRest · 明眸护眼

一款轻量、现代、可高度自定义的 **Windows 护眼定时提醒桌面程序**，基于 **Tauri v2（Rust + React + TypeScript + Tailwind CSS）** 构建。

低内存占用、原生系统托盘常驻、支持多显示器全屏遮罩与柔和弹窗自由切换，所有进阶功能均可在设置中按需开关。

## 核心特性

- **原生系统托盘常驻**：关闭主窗口后自动最小化到右下角托盘继续精准计时；托盘悬停显示实时倒计时，右键快速暂停/继续、立即休息、推迟、切换方案。
- **开机自启动与静默启动**：一键开关 Windows 开机自启动，支持开机后静默驻留托盘不弹窗打扰。
- **科学预设 + 自定义方案**：
  - 内置 4 套常用护眼方案：`20-20-20 护眼法`（20分/20秒）、`经典番茄钟`（25分/5分）、`深度办公`（45分/5分）、`长时学习`（60分/10分）。
  - 支持自由新建、编辑与删除自定义专注/休息周期方案。
- **灵活双提醒模式**：
  - **柔和弹窗提醒**：右下角悬浮卡片，不抢夺键盘输入焦点，可一键展开全屏沉浸休息。
  - **全屏护眼遮罩**：半透明呼吸引导遮罩，支持多显示器同步覆盖、自定义透明度。
  - 支持自由配置“是否允许跳过”、“是否允许推迟及推迟时长”、“休息前倒计时提前预警”，并在设置页一键预览效果。
- **智能免打扰与空闲检测（基于 Win32 原生 API）**：
  - 键鼠空闲 / 锁屏自动暂停计时，回到电脑后自动开启新一轮周期。
  - 全屏游戏、全屏视频、PPT 演示期间自动暂缓弹窗，退出全屏后温和提醒。
  - 支持自定义每日静默免打扰时段（支持跨午夜，如 `22:00`–`08:00`）。
- **6 种治愈提示音与护眼引导**：内置 Web Audio API 本地合成的 6 种音色（晨露风铃、禅意颂钵、林间水滴、暖木拇指琴、柔光钢琴、清心铃磬），零外链、支持卡片试听与音量调节，搭配远眺、眨眼、眼肌与呼吸节奏放松引导。
- **静谧森屿双主题界面**：低眩光浅色森屿与深色夜林主题（支持跟随系统）、60 刻度微光表盘倒计时环与柔雾玻璃质感卡片。
- **每日护眼统计**：本地记录每日用眼时长、完成休息次数、跳过/推迟次数与 7 天趋势图，支持导出 JSON 与清空。

## 本地开发

### 环境要求

- [Node.js](https://nodejs.org/) >= 20
- [Rust](https://www.rust-lang.org/) >= 1.77
- Windows 10 / 11（内置 WebView2 运行时）

### 安装与运行

```bash
# 安装前端依赖
npm install

# 启动开发模式（热重载）
npm run tauri dev
```

### 测试与打包

```bash
# 运行 Rust 计时器与状态机单元测试
cd src-tauri && cargo test

# 前端类型检查与构建
npm run build

# 打包 Windows 可执行文件与安装包
npm run tauri build
```

构建产物位于 `src-tauri/target/release/`（独立可执行文件 `eyerest.exe` 及 `bundle/nsis/` 安装程序）。

> **Windows MinGW (`x86_64-pc-windows-gnu`) 构建提示**：若项目位于包含中文字符的目录中，请先设置纯英文 `CARGO_TARGET_DIR`（如 `$env:CARGO_TARGET_DIR="C:\temp\eyerest-target"`）再执行构建；绿色分发时请将 `eyerest.exe` 与同目录下的 `WebView2Loader.dll` 一并打包。

## 自动化发布（GitHub Actions）

本仓库已内置 [`.github/workflows/release.yml`](.github/workflows/release.yml)。推送 `v*` 标签（例如 `git tag v1.0.0 && git push origin v1.0.0`）即可在 GitHub 云端自动构建 Windows x64 安装包与绿色便携版，并创建 Draft Release。
